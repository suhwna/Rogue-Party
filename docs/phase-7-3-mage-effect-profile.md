# Phase 7-3: Mage Effect Quality Pass

## Summary

- Phase 7 스킬 및 이펙트 품질 재작업의 세 번째 단위다.
- 마법사 계열 이펙트에서 빙결, 운석, 연쇄 번개, 별빛 계열이 서로 다른 형태와 리듬을 갖도록 `renderCrispMageEffect`를 조정했다.
- 서버 판정과 스킬 데이터는 변경하지 않고 Pixi 렌더링 표현만 조정했다.

## 변경 파일

- `public/pixi-skill-effects.js`
  - `renderCrispMageEffect`
    - 빙결:
      - 퍼지는 원형 표현을 줄이고 순간적으로 얼어붙는 shard/crack 중심으로 변경
      - 중심에서 외곽으로 갈라지는 선과 결정 조각을 추가
    - 운석:
      - 더 높은 하늘에서 떨어지는 낙하선으로 조정
      - 착탄 전 target arc, 낙하 중 불꽃 trail, 착탄 후 impact burst와 불꽃 패치 추가
    - 연쇄 번개:
      - 주 전류에 보조 가지 전류를 추가해 연쇄 느낌을 강화
    - 별빛/점멸 계열:
      - rune ring, star, 방사선, spark를 분리해 단순 원형 폭발처럼 보이는 문제를 완화

## 품질 기준

- 빙결은 파란 장판이 아니라 순간적인 결정/균열로 읽혀야 한다.
- 운석은 바닥에서 생기는 폭발이 아니라 하늘에서 떨어지는 물체로 읽혀야 한다.
- 연쇄 번개는 한 줄 beam이 아니라 가지치는 전류로 읽혀야 한다.
- 별빛 계열은 운석/빙결과 색과 형태가 겹치지 않아야 한다.
