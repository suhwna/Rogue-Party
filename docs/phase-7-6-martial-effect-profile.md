# Phase 7-6: Martialist Effect Quality Pass

## Summary

- Phase 7 스킬 및 이펙트 품질 재작업의 여섯 번째 단위다.
- 무투가 계열 이펙트에서 손/발/기합이 모두 비슷한 선이나 원으로 보이는 문제를 줄이고, 각 스킬의 타격 리듬과 실루엣을 구분했다.
- 서버 판정과 스킬 데이터는 변경하지 않고 Pixi 렌더링 표현만 조정했다.

## 변경 파일

- `public/pixi-skill-effects.js`
  - `renderCrispMartialEffect`
    - 파쇄장:
      - 전방 capsule lane, 반복되는 palm arc, 종점 impact burst로 장풍의 폭과 도착점을 더 명확하게 표시
    - 승룡각:
      - 이동 lane 위에 상승하는 발차기 궤적과 단계별 kick line을 추가
      - 최종 타격 위치를 살짝 들어 올려 승룡각의 상승감을 강화
    - 기합 폭발:
      - 단순 원형 장판 대신 짧은 arc 조각, 방사 line, 중심 star로 폭발감을 표현
    - 연환권/연환 흐름:
      - `combo`, `flurry`, `finisher` 계열도 crisp renderer가 직접 처리
      - 여러 주먹 타격 line과 hit spark를 추가해 연속 타격감을 강화

## 품질 기준

- 파쇄장은 전방으로 밀고 나가는 손바닥 충격파로 읽혀야 한다.
- 승룡각은 직선 돌진이 아니라 위로 치켜올리는 발차기로 읽혀야 한다.
- 기합 폭발은 보호/밀쳐내기 계열의 중심 폭발로 읽혀야 한다.
- 연환권은 단발 근접 베기가 아니라 여러 주먹 타격의 리듬으로 읽혀야 한다.
