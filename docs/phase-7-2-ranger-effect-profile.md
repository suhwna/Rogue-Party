# Phase 7-2: Ranger Effect Quality Pass

## Summary

- Phase 7 스킬 및 이펙트 품질 재작업의 두 번째 단위다.
- 궁수 계열 이펙트에서 화살의 발사 방향, 낙하감, 관통 판정 폭이 더 잘 읽히도록 `renderCrispRangerEffect`를 조정했다.
- 서버 판정과 스킬 데이터는 변경하지 않고 Pixi 렌더링 표현만 조정했다.

## 변경 파일

- `public/pixi-skill-effects.js`
  - `renderCrispRangerEffect`
    - 화살비:
      - 단순 원형 장판보다 분절 경계 + 하늘로 쏘는 선행 화살 + 낙하 화살 중심으로 변경
      - 착탄 시점에 작은 arc/spark를 추가해 실제 타격 위치를 더 명확히 표시
      - warning 상태와 실제 발동 상태의 화살 수/alpha를 구분
    - 관통 사격:
      - 관통 lane 폭을 키우고 양쪽 레일을 추가
      - 중앙 화살과 보조 화살을 분리해 방향성과 폭을 동시에 읽을 수 있게 조정
      - 종점 impact를 추가해 피격 위치가 더 잘 보이도록 변경

## 품질 기준

- 화살비는 "바닥에 원이 생김"이 아니라 "위로 쏘고 위에서 꽂힘"으로 읽혀야 한다.
- 관통 사격은 얇은 선이 아니라 실제 판정 lane을 보여줘야 한다.
- 독/일반/암살자 투척 계열과 색상 및 형태가 겹치지 않도록 유지한다.
- 기존 Pixi primitive와 pool 경로를 재사용하고 새 의존성은 추가하지 않는다.
