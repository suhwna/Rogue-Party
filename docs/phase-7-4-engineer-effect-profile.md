# Phase 7-4: Engineer Effect Quality Pass

## Summary

- Phase 7 스킬 및 이펙트 품질 재작업의 네 번째 단위다.
- 기계공 계열 이펙트에서 터렛/지뢰/드론이 즉발 도형처럼 보이는 문제를 줄이고, 투척/설치/기계 작동의 흐름을 더 명확하게 만들었다.
- 서버 판정과 스킬 데이터는 변경하지 않고 Pixi 렌더링 표현만 조정했다.

## 변경 파일

- `public/pixi-skill-effects.js`
  - `renderCrispEngineerEffect`
    - 감전 지뢰:
      - 원형 장판 비중을 낮추고 분절 arc, 이중 gear, 전기 방전, 바닥 베이스를 추가
    - 터렛/장치 투척:
      - `device_throw` 계열은 시작점에서 목표점까지 보간되는 장치 위치를 렌더링
      - 투척 궤적, 장치 본체, 포신, 삼각 지지대, 착지 impact를 추가
    - 드론:
      - gear core, 회전 rotor arc, 하단 본체 라인을 추가해 장치 실루엣을 강화

## 품질 기준

- 설치물은 갑자기 생성되는 느낌보다 투척/조립/착지 흐름이 보여야 한다.
- 지뢰는 일반 원형 장판이 아니라 기계 장치와 감전 위험으로 읽혀야 한다.
- 드론은 구름이나 오브가 아니라 부유 장치로 읽혀야 한다.
- 기존 Pixi primitive와 pool 경로를 재사용하고 새 의존성은 추가하지 않는다.
