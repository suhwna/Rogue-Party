# Phase 7-5: Puppeteer Effect Quality Pass

## Summary

- Phase 7 스킬 및 이펙트 품질 재작업의 다섯 번째 단위다.
- 인형사 계열 이펙트에서 인형이 순간이동처럼 나타나는 느낌을 줄이고, 실 연결과 인형 실루엣이 먼저 보이도록 조정했다.
- 서버 판정과 스킬 데이터는 변경하지 않고 Pixi 렌더링 표현만 조정했다.

## 변경 파일

- `public/pixi-skill-effects.js`
  - `renderCrispPuppetEffect`
    - 기본 실 효과:
      - 주 실과 보조 실을 분리해 연결 방향성을 강화
    - 실 결계:
      - 중심점에서 양끝으로 이어지는 실을 추가
      - 원형 장판 비중을 낮추고 rune/수직 실 기둥 중심으로 조정
    - 피날레 교대:
      - 양끝 위치에 별도 rune ring과 spark를 표시해 교대 지점을 구분
    - 소환/돌진:
      - 목표 위치에 인형 머리/몸통/팔/하단 그림자를 단계적으로 렌더링
      - 본체에서 인형으로 내려오는 조종 실을 추가
      - 돌진/매복은 착지 지점에 짧은 slash arc와 spark를 추가

## 품질 기준

- 인형은 갑자기 생기는 물체가 아니라 실에 매달려 조립되는 존재로 읽혀야 한다.
- 실 결계는 단순 원형 장판보다 실의 연결 구조가 먼저 보여야 한다.
- 교대는 양끝 위치가 동시에 읽혀야 한다.
- 기존 Pixi primitive와 pool 경로를 재사용하고 새 의존성은 추가하지 않는다.
