# 회귀 방지 체크리스트

필요한 검증 시 이 문서를 기준으로 확인한다.

## 자동 체크

- `npm run check`
- `npm run build`
- `npm test`

## 서버 스모크

- 새 포트로 `npm start` 실행 후 `npm run smoke`가 통과한다.
- `/rooms`가 `{ "rooms": [...] }` 형태 JSON을 반환한다.
- `/vendor/pixi.js`가 200으로 응답한다.
- `/client-runtime.js`가 200으로 응답하고 `RogueClientRuntime`을 노출한다.
- `/client-input.js`가 200으로 응답하고 `RogueInputManager`를 노출한다.
- `/client-network.js`가 200으로 응답하고 `RogueNetworkBridge`를 노출한다.
- `/client.js`, `/pixi-renderer.js`, `/styles.css`가 200으로 응답한다.
- WebSocket 연결 후 `ping`에 `pong`이 반환된다.

## 브라우저 수동 체크

- `http://localhost:5173/`에서 메인 화면이 열린다.
- 콘솔 에러가 없다.
- asset 404가 없다.
- Pixi canvas가 비어 있지 않다.
- 방 생성 후 자동 시작 없이 로비에 머문다.
- 대기방에서 직업 변경, 준비, 봇 추가, 관전 버튼이 동작한다.
- 대기방에서 평타, 대시, Q/E/R/F 테스트가 가능하다.

## 전투 체크

- 방장 시작 후 지도 투표 화면이 표시된다.
- 지도 선택은 1회 클릭으로 투표된다.
- 모든 플레이어가 투표하면 즉시 다음 스테이지로 진입한다.
- 전투 중 이동, 대시, 평타, 스킬이 동작한다.
- 피격/타격/스킬 이펙트가 판정 위치와 크게 어긋나지 않는다.
- 레벨업 시 스킬 강화 선택으로 일시 정지 흐름이 걸린다.
- 유물 상자 획득 시 모든 플레이어 선택 후 재개된다.
- 스테이지 클리어 시 남은 유물/경험치 처리 흐름이 보인다.

## 스테이지/보스 체크

- 일반/엘리트/준보스/보스/보상/지키기/막기/랜덤 스테이지가 구분된다.
- 지키기 스테이지에서 몹은 구조체를 우선 공격한다.
- 막기 스테이지에서 특수 이동몹이 왼쪽 도달 전 막기 목표로 동작한다.
- 보스방에서는 보스 중심으로 전투가 진행된다.
- 보스 강공격은 전조가 있고 즉발 억까가 없어야 한다.
- 실패/클리어 후 결과창에서 로비 복귀가 가능하다.

## 성능/정리 체크

- 10분 이상 플레이해도 프레임이 급격히 떨어지지 않는다.
- 화면에 이펙트가 많아져도 입력 지연이 심하지 않다.
- Pixi pool retained 수가 무한 증가하지 않는다.
- 페이지 이동/새로고침 시 heartbeat, reconnect, input listener가 중복 등록되지 않는다.
- low/medium/high 그래픽 품질 변경이 런타임에 반영된다.
