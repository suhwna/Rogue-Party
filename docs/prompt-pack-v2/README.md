## 사용 방법

1. `00_MASTER.md`를 먼저 AI에게 붙여넣습니다.
2. 작업 성격에 맞는 `ROLE` 문서를 추가로 붙여넣습니다.
3. 실제 구현할 기능에 맞는 `FEATURE` 문서를 붙여넣습니다.
4. 결과 코드가 나오면 `07_ROLE_CODE_REVIEW.md`, `20_ROLE_DEBUG.md`, `30_ROLE_BUG_HUNTER.md`로 검수합니다.
